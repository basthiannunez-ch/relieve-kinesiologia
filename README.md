# Javiera Miranda · Kinesióloga

Página web de la kinesióloga Javiera Miranda (Coquimbo). Sitio estático en HTML, CSS y JavaScript, sin paso de build. Se publica en Vercel (framework "Other", comandos de build vacíos).

- `index.html`: contenido de la página
- `styles.css`: estilos (celular primero, modo oscuro automático)
- `script.js`: menú, botones de WhatsApp y aviso de horario. El número de WhatsApp y el Instagram se configuran en las dos primeras constantes.
- `img/`: fotos y logos
